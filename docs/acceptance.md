记录版本、提交 SHA、测试日期、设备型号、系统版本、结果与日志位置；禁止记录密码和私钥。

## 协议与角色
- 正确公钥和密码连接成功；错误公钥、错误密码、无配置均拒绝。
- Host 不得发起连接；Client 不得接收控制；覆盖命令行、IPC、Intent、文件传输入口。
- 私服不可达时不得回退公共服务器；抓包验证无明文会话。
- 验证 Host 可断开会话，停止共享后不可继续控制。
- 无服务器局域网直连：Host 未配置服务器仍显示本机 ID、密码、私有 IPv4。
- Client 可通过 UDP 32119 发现 Host；关闭广播时可手动输入私有 IPv4:32118。
- 首次连接仅输入 IP 和密码；仅成功登录后持久化设备公钥；错误密码、已信任公钥变化、非法地址均拒绝；默认禁止非加密连接。
- 抓包确认直连先完成设备签名校验和加密密钥协商，密码认证及远程会话数据不以明文传输。
- Host 只接受私有 IPv4 来源；Client 默认禁止降级；仅两端主动开启兼容模式时，加密握手失败可进行一次独立非加密私有 IPv4 直连，不得回退公共服务器。

## 局域网网络与安全
- Host 私有 IPv4 监听 TCP 32118；LAN discovery 使用 UDP 32119；防火墙关闭后手动 IP 仍可连接。
- Host 仅接受 RFC1918 私有 IPv4 来源；Client 拒绝公网 IP、域名、IPv6 和非 32118 端口。
- Host 重启后身份保持稳定；重新生成密钥后已信任的客户端必须拒绝，直到用户确认设备更换并清除信任记录。
- 广播发现结果仅作候选信息，不自动信任。首次连接采用 TOFU，不能抵御首次连接中的主动中间人攻击；只在可信局域网使用。

## 发布
- 六种客户端构建及服务端集成测试成功。
- 下载附件并核对 SHA256、APK ABI、包名、签名；桌面解压启动。
- 调试签名版本不得标记生产稳定版。
- 核对完整对应源码与许可证。

- 验证 Client 私服可达与不可达、切换配置、错误公钥（可达不等于认证成功）；Host 验证注册状态。

## 系统级 Host 自启

- Windows 正式安装目录权限、服务账户、自动启动状态、UAC 取消、禁用及卸载。
- Linux root 所有的安装目录、systemd enabled/active、两份配置同步失败、X11/Wayland 登录管理器。
- 首次生成 6 位随机永久密码，重启后使用同一 ID/密码连接；错误密码拒绝；本机重新生成使旧密码失效。
- 在远程会话中重启，等待登录界面，不执行本地登录，验证私服注册和远程连接；不得把服务启动状态等同于远控可用。
- 旧版本升级后核对连接 ID、私服、公钥；测试已存在的新配置不被覆盖及迁移失败保留旧配置。

- Windows ZIP 完整解压后在干净机器运行；Host/Client 分目录，升级不混用旧版 DLL 和资源；与原版 RustDesk 同时运行，TCP 32118 冲突时提示并在释放后恢复；检查两端诊断日志且无密码、私钥及消息正文。

- 兼容模式默认关闭；两端开启后模拟加密握手失败，验证重新建立 TCP、明确协商非加密模式、固定密码认证仍有效、错误密码不降级、已知身份变化不降级、仅一端开启拒绝、跨网/中继保持加密；检查日志中的 lan-plain-fallback-start、lan-plain-fallback-ready 和 lan-plain-host-session。实机验收未完成。
